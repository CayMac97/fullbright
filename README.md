# Fullbright for Horizon

A native **Fullbright / Gamma Utils** mod (`.hnmod`) for [Horizon](https://github.com/horizon-rust/horizon) (Minecraft: Java Edition 26.3 rewrite in Rust).

## Features

- **Instant Full Brightness:** Press **`G`** (rebindable in `Options > Mods > Fullbright`) to toggle maximum brightness (**1000% Gamma** / complete cave and night illumination without shadows).
- **Smooth Transition:** Includes smooth brightness fade animation and HUD status notification.
- **Client-Side Only:** Operates purely on client lightmap state without altering network packets.

## Controls
- **Toggle Fullbright:** `G` (rebindable in `Options > Mods > Fullbright`)
